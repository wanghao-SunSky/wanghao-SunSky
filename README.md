# Hi, I'm SunSky 👋

**3y Backend → AI Agent Engineering.**  
用后端系统思维做 Agent（工具边界 / 状态恢复 / Harness），重度 AI-Native 实践者。

做了 3 年 Java 后端开发（复杂多组织业务重构、权限矩阵、状态机、全量数据双轨迁移，也做过 Python 文档识别模块），现在专注于 **AI Agent 工程与运行时可靠性**。

相比单次 Prompt 的灵光一现，我更关心怎么把大模型放进严肃的软件工程里：

- **职责分离**：划清模型判断与确定性代码的边界，不让概率模型替确定性逻辑背锅。
- **工具副作用与状态恢复**：权限边界、幂等控制、中断恢复（Checkpoint / Replay）与失败兜底。
- **Harness & Eval 思维**：用真实业务状态与双轨对照做闭环验收，而不是靠肉眼看几条 Demo 输出。

### ⚡ AI-Native Practice

我把自己的开发环境和日常生活当成 Agent 的全天候试验场（2025.08 起连续 **280+ 活跃天**重度使用 Codex 及多模型工具链）：

- **Multi-Model Orchestration**：日常运行「主控模型（方案拆解 / 架构审查 / 独立验收）+ 执行模型（编码实现 / 排障测试 / GUI 操作）」的分工流水线。
- **40+ Local Skills & Cross-AI Memory**：沉淀 40+ 个覆盖代码审查、自动化回归、真机控制与日常事务的本地 Skill，并通过 Notion 搭建跨 AI 共享记忆中枢。
- **Work & Life Automation**：从生产系统的全量双轨迁移与定时巡检，到让 Agent 接管滴答清单（GTD + 四象限）、连接真机处理日常事务。
